# PulseWatch

Система мониторинга доступности сервисов цифрового продукта: считает доступность и время ответа по журналу проверок, сравнивает с целевым уровнем (SLO) и формирует оповещения.

## Запуск

```bash
python3 monitor.py checks.csv
```

## Возможности

- доступность, среднее время ответа, 95-й перцентиль и время простоя по каждому сервису (`metrics.py`);
- целевые уровни доступности (SLO), бюджет ошибок и скорость его расхода (`slo.py`);
- оповещения с уровнем критичности и каналом доставки (`alerts.py`);
- каталог сервисов и ответственных команд (`services.py`).

## Тесты
